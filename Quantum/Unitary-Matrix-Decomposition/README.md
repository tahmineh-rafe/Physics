# Unitary Matrix Decomposition

This project implements unitary matrix decomposition using Python.

The unitary matrix used in this example was obtained from:

Arrazola, Juan M., Ville Bergholm, Kamil Brádler, Thomas R. Bromley, Matt J. Collins, Ish Dhand, Alberto Fumagalli et al. "Quantum circuits with many photons on a programmable nanophotonic chip." Nature 591, no. 7848 (2021): 54-60.
